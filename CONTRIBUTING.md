# Contributing

External contributions are welcome through pull requests.

1. Fork this repository and create a branch for your change.
2. Keep the change focused and describe the problem it solves.
3. Open a pull request targeting `main`, with steps to reproduce and details of
   the builds or tests you ran. Include screenshots for visible gameplay or UI
   changes when helpful.

All changes require approval from **@tonga54**, the code owner for every file.
Code changes pushed after approval require a new review. Direct pushes, force
pushes, and deletion of `main` are blocked, including for administrators.

See [README.md](README.md) for build, hosting, and project documentation.
