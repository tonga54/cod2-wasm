# README screenshots

Actual development captures from this project, selected for the main README.
Images are resized to fit within 1600 × 900 and encoded as JPEG; no scene content
has been generated or retouched. These show development builds, so individual
screens can predate later UI refinements. The host's optional weapon pictures
are visible in the class screens; other installations can use the default art.
